## Forbidden Phrases

- "software-only" — never use. Prefer "model-first" or "not in hardware".
- "software problem" — currently in Mission h2. Replace immediately.

## Required Copy Fix

Mission h2 currently reads: "Robotic intelligence is a software problem."
Fix to: "Robotic intelligence is a model problem."
(Fits model-first framing, avoids forbidden phrase, more precise.)

## Italic-Terracotta Device

Rule: max 2 uses across the full page. Currently overused across 5 headings.
- Hero h1 ("embodied intelligence") — keep, it earns it
- One other heading — budget exhausted
- Mission h2, Models h2, Contact h2 — remove italic-terracotta. Plain Instrument Serif only.

**Why:** At 5+ uses the device loses signal. It reads as a default heading style, not an emphasis.
